## 它能做什么

### AI 原创与爆款二创

- **「智能写作」一个面板搞定原创与爆款改写**：贴整篇参考文章就按改写走、贴标题清单就按原创走，按内容自动分流；支持两遍式写作（先事实与结构、再文风精修）、自定义提示词与构思深度，目标字数默认 2000。
- **风格模板**可贴 1~3 篇自己的成稿自建模板，另内置 8 大长文赛道 + 微头条通用共 9 类范文，正文的讲法与语气照你的稿子写。
- 爆款二创先把原文拆成「事实卡」，再只用事实重新组织成新稿，减少原文句式残留；写完后可再过一遍「文本润色」。

### 多平台发布（头条 / 微头条 / 百家号 / 公众号）

- **今日头条**：草稿箱或直接发布，支持批量与软件内定时。
- **微头条**：批量发布与软件内定时，按账号分槽排期。
- **百度百家号**：草稿或直发，支持封面、定时与商品挂载。
- **微信公众号**：一键存草稿箱，内置 28 套排版主题，正文配图自动转存微信图床。
- 头条与百家号登录态物理隔离，账号台账可看分组、粉丝、昨日收入与当日发稿/草稿数。

## 常见问题

**双击被 Windows SmartScreen 拦截？**

点「更多信息」→「仍要运行」。独立商业软件未购买高额 EV 证书时会触发微软拦截提示，本软件通过 Ed25519 签名防篡改核验，绝无任何后门与木马，请放心使用。

**老版本怎么升级？会丢失我写好的文章和小说吗？**

直接下载新版本 Setup 安装包运行覆盖安装即可，**不需要先卸载老版本**。所有作品数据独立保存在本地系统目录，覆盖升级数据毫发无损。

**数据保存在哪里？换电脑怎么备份？**

本机 `C:\Users\<用户名>\AppData\Roaming\XCbot_ToutiaoStudio`。换机前备份该目录，复制到新电脑对应位置即可。

**换电脑了怎么办？**

支持每月 2 次自主解绑换机。在原电脑软件设置中点击「解绑本机」，在新电脑输入原卡密即可直接恢复激活。

**真的能降低机械化表达吗？**

按目前的测试样本（几百篇，覆盖不同题材与长度），改写后套路句式与机械感明显下降，段落衔接更自然。各工具标准会更新，建议发布前复测；不想先装软件，可以先用[在线试用版](https://www.modelscope.cn/studios/lingxiaoyiyu/xcbot)（每天 3 次免费）验证效果。

**端侧 1.5B 润色模型需要独立显卡吗？**

不需要。模型经过底层量化深度优化，普通办公 CPU 即可流畅推理，数秒到十余秒完成一篇 2000 字长文的润色润色。

**公众号能直接群发吗？**

不能。微信接口只开放到草稿箱，零创把稿子和排版存进草稿，最后一步在公众号后台确认发布。

内置通道免配置、按次计费，适合直接用；自备 Key 走你自己的账号，额度与模型自选。

**Q：处理视频需要联网吗？**
不需要。视频重剪、画面处理、变声全部在本机 ffmpeg 完成，不上传素材。
