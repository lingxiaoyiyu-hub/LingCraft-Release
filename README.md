## 核心功能一览

### 1. 爆文下载 · 分类批量抓取与全网爆文筛选

- **一页两卡高效选材**：合并「分类下载」与「全网爆文」两大入口，支持头条作者主页 / 频道批量抓取，以及头条 / 百家号全网高阅读爆文筛选（支持加载更多深挖至 2000 篇）。
- **自动屏蔽官媒及机构号**：默认自动过滤官媒与机构账号，指定作者链接正常放行；自动折叠高风险赛道并给出提示。
- **配图自净化与独立导出**：下载时自动过滤关注引导横幅与章节分隔条，支持按篇导出独立 Word 文档，并可一键勾选批量送入「文章创作」或「文案成片」。

![爆文下载与全网爆文筛选](assets/promo_02_baowen.png)

### 2. 智能写作 + 「必过朱雀」端侧 1.5B 本地润色

- **单遍一次出稿**：合并原创扩写与爆款改写为「智能写作」，贴标题清单按原创走、贴长文按改写走，自动分流；目标字数默认 1800 字，支持三层防中英夹杂护栏与原文配图/AI 生图自动插图。
- **风格模板智能匹配**：默认按题材智能匹配范文并收敛为克制耐读的专栏白话；支持贴 1~3 篇自己的成稿自建专属风格模板，另含独立「AI 找选题」工作区。
- **必过朱雀 · 端侧本地润色**：内置本机 1.5B 量化润色模型，提供「自然通顺（推荐）」与「深度破障」两档强度，支持全文视图与逐段对照精修。改写全程在本机 CPU 完成，**不上传原文、不联网、不消耗云端模型额度**。

### 3. 视频下载、本地重剪与文案成片

- **视频下载**：支持抖音作者主页、单作品、短链及爆款视频批量下载，大文件并发分片提速并支持随时「停止下载」，作品统一入库管理。
- **视频处理（纯本机 ffmpeg）**：全程零联网零模型，提供标准/强烈降重方案、自动消黑边、片头卡与封面帧、22 款变声预设（支持本地试听）以及按画面比例框选模糊去水印；产物另存「已处理」目录，绝不覆盖原片。
- **文案成片（含花生AI 成片）**：支持直接将文章一键转为短视频口播脚本，内置原声 + 7 种常用中文音色、8 首精选 BGM 与自动字幕；接入花生AI 云端成片（扫码登录直出），成片自动落入「视频成果库」，支持 9:16 竖屏与 16:9 横屏，并可在软件内直接发布到今日头条与百度百家号（自动截横版封面）。

### 4. AI 长篇小说工坊

- **仿真书房 + 三栏沉浸创作台**：内置多套仿真书封与自定义装帧，支持 txt / md / docx 整部作品自动识别分卷分章导入，兼容 4 套护眼主题（默认黑金 / 纯净白 / 豆沙绿 / 羊皮卷）。
- **跨卷连续创作**：点击一次按章节顺序自动往下写，每章写完自动定稿并更新摘要、角色履历与记忆卡，跨卷章号连续不串戏；右栏随时调用概要、设定、角色、文风、检测与灵感工具，支持一键排版与全书 Word 导出。

### 5. 多平台发布、IP 隔离与本地排版工具

- **多平台物理隔离发布**：支持今日头条（图文/微头条）、百度百家号直发或存草稿，以及微信公众号一键存草稿箱（内置 28 套精美排版主题，正文配图自动转存微信图床）。
- **出口 IP 隔离与定时发布**：支持代理池配置与按账号绑定独立出口 IP，防串号拦截；支持固定间隔 / 随机间隔 / 时段内随机 / 每日固定时刻 4 种定时发布节奏，按账号独立分槽排期，重启后自动恢复。

## 常见问题

**双击被 Windows SmartScreen 拦截？**
点「更多信息」→「仍要运行」。独立桌面软件未采购高额 EV 代码签名证书时会触发系统提示，本软件通过数字签名防篡改核验，请放心使用。

**老版本怎么升级？会丢失我写好的文章、小说或账号登录态吗？**
直接下载新版 Setup 安装包覆盖安装即可，**不需要先卸载**，所有作品数据与登录状态均会自动保留。

**端侧 1.5B 润色模型和视频处理需要独立显卡吗？**
不需要。端侧 1.5B 润色经过量化优化，普通办公 CPU 即可流畅运行；视频重剪与变声全部在本机 ffmpeg 完成，全程零联网。

**公众号能直接群发吗？**
不能。微信接口只开放到草稿箱，零创负责将文章与排版一键存进草稿箱，最后一步请在公众号后台确认发送。
